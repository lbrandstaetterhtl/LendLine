# Fix report – Security audit 3

As of 2026-09-25. Basis: `security-audit-3.md` (nine findings) and the points of `security-audit-2.md` still open there. Checked with `npm run check` in backend and frontend (typecheck, oxlint including type-aware rules, oxfmt, knip: all green) and with runtime tests against PostgreSQL (curl or Python against the running API, interfaces via headless Edge). Test accounts and test settings were removed or reset to the defaults afterwards.

**Operating notes after the update**

- `npx prisma migrate deploy` in the backend (three new migrations).
- Self-registration is **off** afterwards. Whoever needs it turns it back on under Settings → Registration, ideally with a domain list.
- `LDAP_ADMIN_GROUP` with several entries: now separate them with `;` and use full DNs.
- After the update all users are signed out once (new claim `sv` in the access token); the refresh signs them in again automatically.
